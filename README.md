# AI Audit System

A modern AI spend optimization platform built as a MERN stack audit experience. This project helps teams identify AI tooling waste, recommend right-sized plans, and present shareable audit reports with clear savings insights.

## What it does

- Analyzes AI tool usage across a team
- Suggests optimized pricing tiers and plan adjustments
- Calculates monthly and annual savings
- Generates public audit reports with shareable URLs
- Captures leads and sends transactional email confirmations

## Key features

- Intelligent audit engine for AI tool pricing
- Secure lead capture workflow
- Public audit report sharing with SEO metadata
- PDF export for executive delivery
- Continuous integration and test coverage for backend logic

## Tech stack

- React + Vite frontend
- Express + Node.js backend
- MongoDB database with Mongoose
- Nodemailer transactional email support
- GitHub Actions CI for linting and tests

## Setup

```bash
cd server
npm install
npm start
```

```bash
cd client
npm install
npm run dev
```
